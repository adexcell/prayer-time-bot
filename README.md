# 🕌 Namaz Time Bot (Республика Башкортостан)

Telegram-бот на языке **Go (Golang)** для получения точного официального расписания намаза для всех городов и районов Республики Башкортостан. Данные запрашиваются напрямую из официального API **ДУМ РБ** (Духовное управление мусульман Республики Башкортостан).

---

## ✨ Основные возможности

- **🕌 Точное расписание на сегодня**:
  - Отображает время для всех обязательных намазов и ключевых моментов дня: *Фаджр (Конец Сухура)*, *Восход (Шурук)*, *Зухр*, *Аср*, *Магриб*, *Иша*.
- **🏙 Выбор населенного пункта**:
  - Поддержка **21 города** и **40 районов** Республики Башкортостан.
  - Удобный инлайн-интерфейс с переключением вкладок («Города» / «Районы») и постраничной пагинацией.
  - Выбор города сохраняется индивидуально для каждого пользователя в базе данных.
- **⏰ Гибкая система напоминаний и рассылок**:
  - **Утренняя сводка**: ежедневная отправка полного расписания на день в выбранное время (по умолчанию `06:00`, настраивается от `05:00` до `10:00`).
  - **Напоминание за 15 минут**: предупреждение до наступления каждого намаза.
  - **Уведомление в момент наступления**: оповещение ровно в минуту наступления намаза.
- **⚙️ Интерактивное меню настроек**:
  - Включение и отключение любого типа уведомлений прямо из Telegram с помощью инлайн-кнопок.
- **💾 Автономное хранилище**:
  - База данных **SQLite** на чистом Go (не требует CGO и компилятора gcc при сборке).

## 🛠 Стек технологий

- **Язык**: [Go (Golang)](https://go.dev/) (версия 1.22+)
- **Telegram Bot API**: [`github.com/go-telegram-bot-api/telegram-bot-api/v5`](https://github.com/go-telegram-bot-api/telegram-bot-api)
- **База данных**: SQLite через [`modernc.org/sqlite`](https://gitlab.com/cznic/sqlite) (CGO-free)
- **Планировщик задач**: [`github.com/robfig/cron/v3`](https://github.com/robfig/cron)
- **Конфигурация**: [`github.com/kelseyhightower/envconfig`](https://github.com/kelseyhightower/envconfig), [`github.com/joho/godotenv`](https://github.com/joho/godotenv)
- **Источник данных**: API ДУМ РБ (`https://api.dumrb.com`)

## 🚀 Инструкция по установке и запуску

### 1. Требования

- Установленный **Go** версии **1.22** или выше ([скачать с golang.org](https://go.dev/dl/))
- Токен Telegram-бота, полученный у [@BotFather](https://t.me/BotFather)

---

### 2. Клонирование репозитория

```bash
git clone https://github.com/your-username/namaz-time-bot.git
cd namaz-time-bot
```

---

### 3. Настройка переменных окружения

Скопируйте пример файла конфигурации:

```bash
cp .env.example .env
```

Откройте файл `.env` в текстовом редакторе и укажите ваш токен:

```env
TELEGRAM_BOT_TOKEN=1234567890:ABCdefGhIJKlmNoPQRsTUVwxyZ
CITY=Уфа
COUNTRY=Russia
METHOD=13
```

Параметры:
- `TELEGRAM_BOT_TOKEN` *(обязательно)* — токен бота от @BotFather.
- `CITY` *(обязательно)* — город по умолчанию (например, `Уфа`).
- `COUNTRY` *(обязательно)* — страна (например, `Russia`).
- `METHOD` *(обязательно)* — метод расчета времени.

---

### 4. Установка зависимостей

```bash
go mod download
```

---

### 5. Запуск

#### Режим разработки:
```bash
go run main.go
```

#### Сборка и запуск бинарного файла:
```bash
# Сборка исполняемого файла
go build -o namaz-bot main.go

# Запуск
./namaz-bot
```

## ⚙️ Развертывание на сервере (Systemd сервис)

Для непрерывной работы бота на Linux-сервере (Ubuntu/Debian/CentOS) можно создать systemd-сервис:

1. Соберите бинарник на сервере:
   ```bash
   go build -o /opt/namaz-bot/namaz-bot main.go
   ```

2. Создайте файл сервиса `/etc/systemd/system/namaz-bot.service`:
   ```ini
   [Unit]
   Description=Namaz Time Telegram Bot
   After=network.target

   [Service]
   Type=simple
   User=root
   WorkingDirectory=/opt/namaz-bot
   ExecStart=/opt/namaz-bot/namaz-bot
   Restart=always
   RestartSec=5

   [Install]
   WantedBy=multi-user.target
   ```

3. Активируйте и запустите сервис:
   ```bash
   sudo systemctl daemon-reload
   sudo systemctl enable --now namaz-bot
   ```

4. Просмотр логов:
   ```bash
   sudo journalctl -u namaz-bot -f
   ```
